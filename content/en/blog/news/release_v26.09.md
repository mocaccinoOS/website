### Changes since 26.08

- Kernel upgraded to 6.18.50 (LTS)
- Mesa version 26.2.1
- COSMIC 1.7.0

### Issues and improvements

- Added optional [x86-64-v3 optimized](https://www.mocaccino.org/blog/2026/08/05/new-optional-x86-64-v3-builds-zero-risk-for-everyone-else/) builds for improved performance on supported modern CPUs.
- Improved Intel CPU/platform support, including Raptor Lake systems. ( https://github.com/mocaccinoOS/desktop/commit/ad3a6a020abd9d17fe313395144b36afc79c0f6c )
- Improved ASUS ROG/Armoury hardware support for asusctl ( https://github.com/mocaccinoOS/desktop/commit/aa597e5e603de87a7884ded3d0b0aa2ca7551fa6 )

### Help Us Improve MocaccinoOS

### Project sustainability note

MocaccinoOS is currently supported by community donations totaling **approximately $1 per month**.
While development continues, this level of funding is not sufficient to sustainably support long-term work.

If you find MocaccinoOS useful and would like to help keep the project healthy, consider supporting us via donations.

https://www.mocaccino.org/docs/donate/
